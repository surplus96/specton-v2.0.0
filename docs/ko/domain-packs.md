# 도메인 팩과 문서 입출력

[![한국어](../assets/lang-ko.svg)](../ko/domain-packs.md) [![English](../assets/lang-en.svg)](../en/domain-packs.md)

## 팩의 역할

팩은 실행 전에 준비하는 명명 사전·표준 도메인·업무 용어·설계 패턴·에이전트 예시다. 앱 기능 코드나 모든 업무 규칙의 구현체가 아니다. 도메인이 바뀌면 해당 팩과 고객 설계를 읽되 같은 분석·명세·생성 파이프라인을 사용한다.

| 팩 | 저장소 기준 버전 | 역할 |
|---|---|---|
| `common` | 0.1.8 | 표준 단어·분류어·도메인·명명·저장 타입 정책 |
| `inventory` | 0.1.23 | 재고·자재·입출고 관련 용어·패턴 |
| `maintenance` | 0.1.9 | 설비·보전·작업·계측 관련 용어·패턴 |

버전·승인 여부의 기준은 각 `manifest.yaml`과 `pack.lock`이다. 서버의 `GET /api/v1/packs`는 팩과 공통 팩의 형식·출처·승인·해시를 검사한다. 초안·손상된 팩은 선택 및 실행 생성 단계에서 거절한다. 화면 이름과 설명은 `catalog.yaml`에 둔다.

## 파일과 수정 순서

| 입력 파일 | 용도 |
|---|---|
| `manifest.yaml` | 이름·버전·출처·승인 상태 |
| `term_specs.yaml`, `words.yaml` | 업무 용어 조합과 추가 단어 |
| `patterns.yaml`, `examples/A01.yaml` 등 | 설계 패턴과 개발용 구조화 예시 |
| `naming.yaml`, `rules.yaml` | 공통 명명·검토 정책 |
| `standard_selection.yaml` | 공식 이음동의어·금칙어 선별 사유 |
| `lexicon_sources.yaml`, `sources/` | 공개 사전 사본·판·해시·선정 근거 |

`GENERATED` 표시 파일과 lock은 생성기가 관리한다. 같은 파일명이라도 팩별 입력/생성 여부를 파일 머리말에서 확인한다.

1. 수정할 팩의 manifest 버전을 올린다. 승인 상태 변경도 콘텐츠 변경이다.
2. 입력 YAML을 수정하고 원문·출처를 검토한다.
3. 아래 명령으로 생성·일치 여부를 검사한다.
4. `terms.yaml`, 공통 `words.yaml`·`domains.yaml`, lock 변경을 함께 검토한다.

```bash
uv run python -m specton.packs.build
uv run python -m specton.packs.build --check
```

같은 버전에 다른 콘텐츠 해시를 기록할 수 없다. 공통표준 CSV와 재고 공개 출처의 인코딩·개행은 해시 입력이므로 임의 변환하지 않는다. 이름 길이·분류어·도메인·중복 물리명을 검사한다. 공개 출처와 라이선스 안내는 [자료 근거](domain-pack-sources.md)를 따른다.

## 명명과 타입

논리명과 물리명을 분리하고, 물리명은 팩 정책에 따라 소문자·구분자·PostgreSQL 식별자 길이를 적용한다. `strict`와 `pg_native` 저장 프로필은 같은 정책으로 생성·검증해야 한다. 숫자 정밀도·필수 여부·복합 키·관계 출처를 잃지 않는다. 공식 단어, 관측된 사용 방식, 프로젝트 선택을 구별한다.

새 팩을 추가할 때 용어만 늘리는 것으로 완료하지 않는다. 설계 추출, 요구-기능-저장 연결, 지원 계약 표현, 정상·경계·실패 인수 사례를 함께 검증한다. 평가 정답을 few-shot 예시에 복사하지 않는다.

## 입력·출력 계약

Excel/CSV는 요구사항 ID·명칭·상세 열을 읽고 시트·행을 보존한다. 지원하는 HWP/HWPX 요구사항 표는 구역·문단·표·셀 출처를 보존한다. 손상·암호화·추출 불가 입력은 설명과 함께 거절한다. 추출 실패를 빈 정상 요구사항으로 바꾸지 않는다.

최종 산출물은 기능 명세(Markdown·선택적 PDF), ERD(Mermaid·선택적 PDF), DDL(SQL), RTM(CSV/XLSX)이다. revision·모델·파일 해시로 같은 승인 버전인지 확인한다. PDF 입력·OCR 및 자유 서술형 문서 전체 해석은 지원 범위와 구별한다.
