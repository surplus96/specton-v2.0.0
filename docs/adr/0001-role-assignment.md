# ADR-0001 개인 개발 운영

- 날짜: 2026-11-14
- 상태: 적용

## 배경

독립 저장소에서 개인 유지보수와 확장을 진행할 수 있는 작업 규칙이 필요하다.

## 결정

개발자가 전체 모듈을 유지하고, 변경별로 영향 분석·검증·문서를 함께 관리한다. 계정 기반 코드 소유자 지정과 외부 보드 자동화는 사용하지 않는다. 모듈별 책임은 [개발 운영](../08-roles.md)에 기술 경계로 기록한다.

제품 사용자의 HITL 승인과 개발 변경 검토는 별개다. 개인 개발 방식으로 바꾸어도 실행 중 승인·SQL 검증·산출물 해시 검사는 유지한다.

## 결과

로컬 환경에서 작업을 시작할 수 있다. 평가 자료는 개발 자료와 분리하고, 관측 후 보완 결과는 회귀 평가로 표시한다. 원격 저장소의 권한·CI·보호 규칙은 연결 시 실제 설정을 확인한다.
