# ADR-0014 평가 데이터와 독립성

- 날짜: 2026-11-14
- 상태: 개인 개발 기준 적용

## 결정

개발용 입력과 인수용 입력을 분리하고, 평가 전에 팩·프롬프트·정답·수용 기준을 버전과 해시로 고정한다. 기존 재고 5건 평가와 후속 관측 수치는 그대로 보존한다. 설비 확대는 별도 범위로 정한다.

같은 개발자가 정답과 구현을 모두 보았으면 회귀·진단 평가로 표시한다. 새로 작성한 합성 자료를 미열람 평가나 과거 승인 자료의 복구본으로 표시하지 않는다. 정답을 구현에 맞추어 변경하지 않고 변경 시 독립된 요구 근거를 남긴다.

원문·정답·승인 파일은 비공개 평가 저장소에서 관리하고, 공개 가능한 집계와 합성 테스트만 코드와 함께 보관한다. 미완료·미생성·실패를 분모에서 임의로 제외하지 않는다.

## 결과

평가의 재현성과 한계를 함께 설명할 수 있다. 이전 평가 도구의 승인 JSON 계약은 호환 대상으로 유지한다. 새 실행 명세와 인수 테스트의 검증 기준은 [개발 계획](../planning/README.md)에 정의한다.
