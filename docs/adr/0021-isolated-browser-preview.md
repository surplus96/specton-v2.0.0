# ADR-0021: 고정 브라우저 인수와 소유자 중계 미리보기

- 날짜: 2026-11-14
- 상태: 구현

## 배경

DB·HTTP 통과만으로 생성 화면을 사용할 수 있다고 판정할 수 없다. 생성 앱을 플랫폼 origin에서 직접 열거나 임의 포트 URL을 노출하면 플랫폼 인증·코드 실행 경계가 섞인다.

## 결정

고정 Playwright/Chromium 이미지에서 승인 소스를 오프라인 빌드하고 명시적 화면 시나리오를 실행한다. 검증 이미지·스크립트·빌드 파일·스크린샷을 해시에 연결한다. 자연어 업무 인수와 브라우저 고정 프로필의 결과는 구분한다.

브라우저 통과 소스로 15분짜리 미리보기 자원을 만든다. 앱·DB는 internal 네트워크에 유지하고, 고정 API 중계기만 루프백 포트를 연다. API 서버는 세션·소유권·CSRF·만료와 승인 메서드/경로를 확인한 뒤 중계한다. 브라우저에는 포트·토큰 대신 sandbox srcdoc과 제한된 메시지 연결을 제공한다. 같은 origin 권한은 주지 않는다.

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 플랫폼에서 생성 HTML 직접 서비스 | 쿠키·DOM 실행 경계를 공유하므로 제외 |
| 공개 미리보기 URL·외부 DNS/인증 서비스 | 초기 로컬 단계보다 운영 범위가 커져 후속 검토 |
| internal 앱에 호스트 포트만 publish | 해당 Docker 구성에서 공개되지 않아 고정 중계 컨테이너로 분리 |
| 자연어 인수 전부 자동 통과 | 실제 실행한 고정 시나리오와 의미가 달라 제외 |

## 결과

프레임은 부모 DOM·저장소에 접근하지 못하고 API 접근은 소유자 세션과 만료에 묶인다. 단일 루프백 호스트 구성이 필요하며 물리 자원 회수는 작업자 운영에 의존한다. 고정 신뢰 소스만 실행하고 임의 외부 웹사이트·사용자 코드 실행은 지원하지 않는다. 상세 계약은 [구현 기록](../planning/14-browser-preview-implementation.md)에 있다.
