# ADR-0019: 승인 정책 기반 생성 재고 원장

- 날짜: 2026-11-14
- 상태: 구현

## 배경

원본 DDL과 자연어 요구만으로 수량 정밀도·음수 허용·취소 정책을 추정하면 승인되지 않은 업무 의미를 구현하게 된다. 기존 기준정보 생성기는 재고 상태 전이와 동시성 처리를 지원하지 않는다.

## 결정

`spec-v0.3`에 명시적 `stock-ledger-v1` 정책을 추가한다. 창고·품목 엔티티, 소수 세 자리, 음수 불가, 입고 취소 잔량 조건, 여섯 API와 `generated-ledger-v1` 저장을 별도 승인한다. 원본 네 산출물을 보존하고 생성 앱 DB에 이동·잔량·원장 표를 추가한다.

한 이동은 한 창고·품목·수량으로 제한한다. Decimal과 numeric(18,3), 이동/잔량 행 잠금, 잔량·원장·상태·멱등 결과의 단일 트랜잭션을 사용한다. 취소는 삭제 대신 역방향 원장 기록이다. 호출자·API·명령 키에 묶인 요청 해시는 대상 이동 ID를 포함한다.

자연어 인수는 자동 성공 처리하지 않는다. 고정 신뢰 검증기로 실제 격리 DB·HTTP의 정상/거절·동시성·오류 롤백을 검사한다. 플랫폼 자동 실행과 브라우저 인수는 별도 단계다.

## 검토한 대안

| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 원본 표에 동작 추론 | 연결 편의 | 명시되지 않은 상태·정밀도·취소 의미를 추정함 |
| 범용 규칙 언어·임의 생성 코드 | 높은 확장성 | 초기 검증 경계와 실행 안전성을 확보하기 어려움 |
| 잔량만 갱신 | 단순 구현 | 취소·감사·원장 합계 검증 근거가 없음 |

## 결과

정책과 소스·검증 해시를 연결하고 기존 명세 해시를 유지한다. 제한된 생성 원장 저장소에 동의해야 하며 다중 행 전표·예약·이동·운영 인증은 지원하지 않는다. 상세 계약과 실제 검증은 [재고 구현 기록](../planning/12-inventory-ledger-implementation.md)에 있다.
